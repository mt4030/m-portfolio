# Mohsen's Portfolio

Modern personal portfolio website built with **React**, **Tailwind CSS**, **GSAP** animations, and a clean, responsive design.


![Hero section preview](public/img/bg.png)  
*(or replace with a better screenshot – recommended size: ~1200×600px)*

## ✨ Features

- Responsive design (mobile-first)
- Smooth GSAP scroll-triggered animations & hero parallax/tilt effect
- Interactive skill cards with hover progress bars
- Project showcase with live & GitHub links
- Clean contact section with social icons
- Minimal dark theme with amber accents

## 🛠️ Tech Stack

| Category       | Technologies                                 |
|----------------|----------------------------------------------|
| Frontend       | React, TypeScript, Tailwind CSS, shadcn/ui   |
| State / Data   | TanStack Query (React Query), Redux Toolkit  |
| Animations     | GSAP, ScrollTrigger, SplitText               |
| Icons          | react-icons                                  |
| Deployment     | Netlify                                      |
